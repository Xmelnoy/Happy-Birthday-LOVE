# Happy-Birthday-LOVE

Романтичный одностраничный сайт-подарок на день рождения, созданный на React + TypeScript + Vite.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Что уже реализовано

- Стартовый экран с кнопкой «Открыть подарок» и анимированным переходом
- Hero-блок с по-буквенной анимацией заголовка и счётчиком времени вместе
- Любовное письмо с рукописным шрифтом
- Галерея в стиле polaroid + добавление фото (input / drag&drop) + localStorage + лайтбокс
- Timeline с готовыми событиями и формой добавления новых событий + localStorage
- Блок «Почему я тебя люблю» с модалкой добавления причин + localStorage
- Финальный блок пожеланий с анимацией падающей звезды
- Футер с пульсирующим сердцем
