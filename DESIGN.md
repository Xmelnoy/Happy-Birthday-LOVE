Design brief — Happy Birthday LOVE

Создай премиальный интерактивный романтический one-page website “Happy Birthday LOVE” — цифровой подарок для любимого человека.

Сайт должен ощущаться не как обычный лендинг, а как маленькая персональная интерактивная вселенная, созданная специально для одного человека.

Главное настроение:

romantic · cinematic · elegant · intimate · dreamy · emotional · premium · magical

Не использовать визуальный стиль типичного шаблонного Valentine's Day сайта. Нужен современный дизайн уровня premium digital experience.

1. Общая визуальная концепция

Основная концепция — ночное романтическое пространство, в котором сочетаются:

глубокий тёмный фон;
бордовые / винные / розовые оттенки;
мягкое золотистое свечение;
стеклянные полупрозрачные карточки;
большие выразительные заголовки;
тонкие линии;
звёзды;
падающие лепестки;
частицы;
световые ореолы;
размытие;
объём;
параллакс;
плавные cinematic-анимации.

Фон не должен быть плоским.

Он должен иметь несколько визуальных слоёв:

тёмный градиент;
большие размытые световые пятна;
мелкие звёзды;
падающие звёзды;
лепестки;
мягкое свечение вокруг курсора;
едва заметную текстуру / noise;
декоративные световые линии.

При движении мыши фон должен слегка реагировать на положение курсора.

Вокруг курсора появляется мягкое radial glow, которое плавно следует за мышью.

Не делать резкого следования — движение должно быть плавным и дорогим визуально.

2. Первый экран — Opening / Gift

Первый экран занимает весь viewport.

Это главный эмоциональный момент сайта.

Композиция

В центре находится большой подарок, который является главным интерактивным объектом.

Вокруг подарка:

мягкий glow;
несколько светящихся орбит;
маленькие частицы;
сердца;
звёзды;
лёгкое свечение;
небольшие декоративные элементы.

Подарок должен выглядеть объёмным, практически как 3D object.

Он слегка парит вверх-вниз.

При наведении:

увеличивается;
немного поворачивается;
усиливается glow;
появляются дополнительные частицы.

Под подарком:

«Нажми, чтобы открыть»

Текст слегка пульсирует.

3. Заголовок первого экрана

Над подарком располагается небольшой elegant eyebrow:

для самого дорогого человека

Затем большой заголовок:

С Днём Рождения, [ИМЯ]!

Заголовок должен быть очень выразительным.

Использовать сочетание:

elegant serif typography для основного текста;
modern sans-serif для вспомогательного текста.

Например:

Cormorant Garamond / Playfair Display / DM Serif Display

в сочетании с:

Manrope / Inter / Plus Jakarta Sans

Заголовок не должен выглядеть как обычный HTML heading.

Каждая буква может появляться отдельно с небольшой задержкой.

Анимация:

fade;
slight vertical movement;
subtle rotation;
blur → sharp.
4. Текст поздравления

Под заголовком:

Я приготовил для тебя маленькую вселенную.

И ниже:

Нажми на подарок — и начнём нашу историю.

Текст должен появляться после заголовка.

Не использовать слишком много текста на первом экране.

Главный фокус:

имя → подарок → CTA.

5. Анимация открытия подарка

При клике на подарок:

подарок слегка сжимается;
появляется яркая вспышка;
крышка открывается;
из подарка вылетают:
сердца;
лепестки;
звёзды;
светящиеся частицы;
экран получает небольшую cinematic transition;
первый экран плавно растворяется;
появляется основная страница.

Transition должен ощущаться как:

“открылась маленькая вселенная”

а не как обычный fade transition.

6. Основной Hero

После открытия подарка появляется основной сайт.

Большой hero section:

С Днём Рождения, [ИМЯ]!

Под ним:

Потому что сегодня родилась ты — и однажды наши дороги встретились.

Ниже располагается карточка:

Мы вместе уже

1234 дней

12 часов

35 минут

Карточка стеклянная, с blur и лёгким glow.

7. Floating background

На протяжении всей страницы должны существовать живые фоновые элементы:

Falling petals

Плавно падающие лепестки.

Они должны:

немного вращаться;
двигаться по синусоидальной траектории;
иметь разную скорость;
иметь разный размер;
иногда исчезать;
появляться снова.

Не должно быть ощущения, что это одинаковые элементы, клонированные несколько раз.

Falling stars

Добавить отдельный слой падающих / летящих звёзд.

Некоторые звёзды:

падают вертикально;
некоторые летят по диагонали;
некоторые оставляют короткий светящийся след.

Количество небольшое.

Они должны быть декоративными, а не мешать чтению.

8. Cursor interaction

На desktop при движении мыши:

вокруг курсора появляется:

soft radial light

с большим blur radius.

Также некоторые фоновые элементы могут немного двигаться относительно курсора.

Например:

звёзды — 2–4 px;
большие glow objects — 5–15 px;
декоративные элементы — до 20 px.

Эффект должен создавать ощущение глубины.

9. Love Letter

Следующая секция:

Моё любовное письмо

Большая glassmorphism карточка.

Внутри длинный персональный текст.

Карточка должна выглядеть как:

современное цифровое письмо.

Можно добавить:

маленькую дату;
декоративную линию;
handwritten-style accent;
маленькое сердце;
подпись.

При появлении секции:

карточка плавно появляется снизу и слегка разворачивается по X-axis.

10. Memories Gallery

Секция:

Галерея воспоминаний

Это не обычная сетка фотографий.

Сделать визуально похожей на:

luxury memory wall / polaroid gallery.

Фотографии могут иметь небольшой наклон.

При hover:

фотография выравнивается;
увеличивается;
появляется glow;
caption становится видимым;
соседние карточки слегка отодвигаются.

Поддержать:

загрузку фотографий;
drag & drop;
открытие фотографии в fullscreen lightbox.

Добавить кнопку:

+ Добавить фото

11. Our Story / Timeline

Секция:

Наша история

Вертикальная timeline.

Центральная светящаяся линия.

На ней располагаются события отношений.

Например:

14.02.2023

Наше первое свидание

День, когда всё началось.

Следующее событие:

Первый поцелуй

Следующее:

Первая поездка

И т.д.

Карточки располагаются по разные стороны timeline.

При скролле:

линия постепенно подсвечивается;
карточки появляются одна за другой;
фотографии слегка увеличиваются;
точки timeline glow.

Пользователь может добавлять собственные события.

12. Reasons — главная интерактивная секция

Не делать обычный список:

Причина 1
Причина 2
Причина 3

Вместо этого создать категории любви.

Заголовок:

Почему я тебя люблю

Подзаголовок:

Наверное, одной страницы никогда не хватит, чтобы перечислить всё.

Категории

Каждая категория — большая интерактивная карточка.

Например:

♡ Твоя душа

Всё то, что делает тебя именно тобой.

✦ С тобой счастливее

Маленькие моменты рядом с тобой превращаются в самые дорогие воспоминания.

∞ Мы вместе

Про поддержку, уют и чувство дома рядом друг с другом.

Карточки должны быть визуально разными.

Использовать:

номер категории;
большую декоративную иконку;
название;
описание;
количество причин;
стрелку →.

Hover:

карточка поднимается;
появляется glow;
фон становится немного светлее;
декоративные элементы двигаются.
13. Opening category

При клике на категорию она должна открываться с красивой transition-анимацией.

Например:

карточка увеличивается → становится полноценной панелью.

После открытия:

Твоя душа

Всё то, что делает тебя именно тобой...

А ниже:

02

03

Причины появляются последовательно.

14. Add reason

Внутри категории должна быть кнопка:

+ Добавить причину

Открывается красивое modal window.

Заголовок:

Добавить ещё одну причину

Textarea:

Напиши, почему ты её любишь...

Кнопка:

Сохранить причину

После сохранения:

новая причина появляется с animation;
карточка слегка подсвечивается;
появляется маленькая particle animation.
15. Add category

Также должна быть карточка:

+ Добавить свою главу

При клике:

Modal:

Создать категорию

Поля:

Название;
Краткое описание.

После создания новая категория появляется в общем списке.

Все категории и причины должны сохраняться в:

LocalStorage

16. Wishes

Секция:

Твои желания ✨

Это отдельная интерактивная часть.

Пользователь может написать своё желание.

Например:

Съездить вместе к морю

После добавления желание появляется в списке.

Каждое желание имеет checkbox.

Статусы:

○ хочу

✓ исполнено

При выполнении:

checkbox красиво анимируется;
текст становится немного прозрачнее;
появляется небольшая sparkle animation;
счётчик выполненных желаний обновляется.

Например:

3 из 7 желаний исполнено

Под ним progress bar.

17. Shooting Star

После добавления нового желания через экран может пролетать падающая звезда.

Идея:

пользователь пишет желание → нажимает сохранить → желание визуально превращается в звезду → звезда улетает вверх.

Это должно символизировать:

«загадай желание»

Состояния:

🔇 музыка выключена

20. Footer

В самом низу:

маленькое сердце.

Текст:

21. Design system
Цвета

Основной фон:

#09070B / #100910

Основные оттенки:

deep burgundy;
wine red;
dusty rose;
soft pink;
champagne gold;
warm white.

Не использовать ярко-красный.

Цвета должны быть приглушёнными и дорогими.

Typography

Headings:

Cormorant Garamond / Playfair Display

Body:

Manrope / Inter

Большие заголовки.

Много воздуха.

Небольшое letter-spacing.

22. Cards

Все карточки должны иметь:

border-radius: 20–32px;
тонкую прозрачную border;
backdrop blur;
мягкую тень;
внутренний glow;
hover transition.

Но не превращать весь сайт в набор одинаковых стеклянных карточек.

Часть элементов должна быть:

текстовой;
прозрачной;
декоративной;
с линиями;
с градиентами.
23. Animation philosophy

Анимации должны быть:

slow · smooth · cinematic · organic

Не использовать резкие bounce-анимации повсюду.

Основные типы:

fade;
blur;
scale;
parallax;
floating;
glow;
rotate;
stagger;
morph.

Каждая секция должна иметь собственное появление при scroll.

24. Responsive

Desktop:

широкий cinematic experience.

Tablet:

уменьшить декоративные элементы.

Mobile:

один столбец;
крупные touch targets;
timeline превращается в одну вертикальную линию;
категории идут вертикально;
подарок остаётся центральным объектом;
фоновые эффекты становятся менее интенсивными.

Не перегружать мобильную версию анимациями.

Учитывать:

prefers-reduced-motion.

25. Главное требование

Сайт должен создавать ощущение:

«Это не сайт. Это подарок, который для меня сделали лично».

Он должен быть:

дорогим визуально, эмоциональным, интерактивным, глубоким и запоминающимся.

Не делать:

обычный landing page;
шаблон Valentine's Day;
большое количество одинаковых карточек;
чрезмерно яркий красный;
дешёвые bounce-анимации;
перегруженный UI;
стандартные Bootstrap-like компоненты.

Главный визуальный ориентир:

cinematic romantic digital experience + luxury editorial design + interactive story.
